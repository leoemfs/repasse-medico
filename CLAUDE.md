# Regras de trabalho deste repositório

- **Sempre prévia primeiro.** Antes de implementar qualquer mudança de tela ou de fluxo, mostrar uma prévia visual navegável, **sem código do app**, com **fidelidade visual ao aplicativo**: usar o `src/styles.css` real, o menu e os ícones de `src/index.html` e dados fictícios. Guardar a prévia em `docs/prototipos/`. Só implementar depois que o usuário aprovar a prévia.
- Pedidos de «só registre / documente» não mexem no código: vão para `docs/proximas-funcoes.md`.
- Regras de negócio só em `src/engine/`; testes e publicação conforme o README.
